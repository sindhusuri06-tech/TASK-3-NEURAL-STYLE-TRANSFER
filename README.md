# Task 3 – Neural Style Transfer

## Description
This project implements a Neural Style Transfer system using a pre-trained deep learning model.
The model applies artistic styles from one image to another image.

## Requirements
- Python
- TensorFlow
- TensorFlow Hub
- OpenCV

## Files
- neural_style_transfer.py – main Python script
- content.jpg – input image
- style.jpg – style image
- output.jpg – stylized output image

## Output
The output image is generated by combining the content of one image with the artistic style of another image.
